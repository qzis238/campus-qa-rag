# 校园知识问答助手（RAG）

基于 **检索增强生成（RAG）** 的校园知识问答系统。将校园制度文档向量化入库，用户提问时先检索相关内容，再让大模型**严格基于检索到的资料**作答，有效缓解大模型「幻觉」问题，让回答有据可依。

## 技术栈

| 模块 | 技术 |
|------|------|
| 语言 | Python 3 |
| 向量数据库 | ChromaDB（本地持久化） |
| Embedding 模型 | 智谱 GLM `embedding-3` |
| 大模型 | 智谱 GLM `glm-4-flash` |
| 调用方式 | OpenAI SDK（兼容接口） |

## RAG 核心流程

```
文档 → 切分 → Embedding 向量化 → 存入 ChromaDB
                                      ↑
用户提问 → 向量化 → 相似度检索 top-k → 拼接上下文 → 大模型生成回答
```

1. **文档加载**：读取 `data/` 目录下的文本文件
2. **文本切分**：长文档按 500 字切块（50 字重叠，避免语义被切断）
3. **向量化**：调用 Embedding 模型把每个文本块转成向量
4. **存储**：向量存入 ChromaDB，支持持久化与相似度检索
5. **检索**：用户问题向量化后，检索语义最相近的 top-k 个片段
6. **生成**：将检索片段 + 问题拼成提示词，让大模型基于资料作答

## 项目结构

```
campus-qa-rag/
├── data/              # 知识库文档（放入 .txt / .md）
├── build_index.py     # 构建向量索引
├── ask.py             # 交互式问答入口
├── test_query.py      # 批量问答演示脚本
├── .env               # API 密钥（不上传）
└── requirements.txt   # 依赖
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置密钥

在 `.env` 中填入智谱 API key：

```
ZHIPU_API_KEY=你的key
```

### 3. 放入知识库文档

将制度/资料文档（`.txt` 或 `.md`）放入 `data/` 目录。

### 4. 构建索引

```bash
python build_index.py
```

### 5. 问答

```bash
python ask.py
```

## 效果演示

以商丘学院《学生管理制度》为知识库：

```
问：学生考试作弊会受到什么处分？
答：……根据第五十二条规定，严重作弊行为给予开除学籍处分；
    情节较轻的给予警告、严重警告、记过、留校察看等处分。

问：学生可以申请休学吗？
答：可以。经学校批准可以休学，休学次数和期限按《学籍管理细则》执行。
```

对于知识库中没有的内容，系统会诚实回答「资料中没有相关信息」，而不是像纯大模型那样凭空编造。
